1. PREREQUISITES
--------------------------------------------------------------------------------

    pip install fastapi uvicorn pydantic

2. HOW TO START THE SERVER
--------------------------------------------------------------------------------
Step 1: Open PowerShell or Command Prompt.
Step 2: Navigate to the application folder:
    cd "C:\Users\Axxer\Documents\AdZU_Ideathon\ADZU-ideathon\AdZU_Ideathon"

Step 3: Run the local dev server:
    python -m uvicorn main:app --reload --port 8000

(Note: If you want to access the app from your mobile phone over local Wi-Fi, run:)
    python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload

4. HOW TO TEST OFFLINE-FIRST MODE (GIDA RESILIENCE)
--------------------------------------------------------------------------------
1. In http://localhost:8000/index.html, click the red "Island Outage" button in the top bar.
2. Submit a high-acuity patient referral (e.g., Severe Trauma).
3. Observe:
   - Form does not fail or hang.
   - Ticket is badged as "AES-256 VAULT".
   - "Device Vault" KPI counter increments.
4. Click "Online" / "Reconnect":
   - The queue auto-flushes to the backend FHIR R4 repository.
   - Badge converts to "FHIR R4 HUB".

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
Run regression and HL7 FHIR conformance tests:
